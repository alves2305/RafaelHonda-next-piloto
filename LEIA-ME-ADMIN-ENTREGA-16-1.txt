PAINEL ADMINISTRATIVO — FASE 3 / ENTREGA 16.1
PERFORMANCE DO CATÁLOGO

O QUE FOI MELHORADO

1. CACHE DO CATÁLOGO

Os dados públicos ficam em cache por 30 segundos.

Na primeira visita o sistema consulta o Supabase. As visitas seguintes dentro
desse período reaproveitam o resultado e evitam novas consultas completas.

As alterações feitas pelo painel podem levar até 30 segundos para aparecer no
catálogo público.

2. MENOS DADOS ENVIADOS AO CELULAR

A página principal não envia mais descrições completas, benefícios, fichas
técnicas e todos os valores de parcelas para o componente de pesquisa.

O navegador recebe somente:

- id;
- nome;
- slug;
- categoria;
- imagem;
- disponibilidade de consórcio;
- disponibilidade de financiamento.

As informações completas continuam disponíveis nas páginas individuais.

3. IMAGENS RESPONSIVAS

As imagens locais e as imagens públicas do Supabase agora usam a otimização do
Next.js.

O servidor entrega tamanhos diferentes para celular, tablet e computador.

Links externos que não pertencem ao Supabase continuam usando a imagem original
para evitar incompatibilidade.

4. CARREGAMENTO PREGUIÇOSO

As imagens das motos abaixo da área visível são carregadas conforme o cliente
rola a página.

5. SEM PRÉ-CARREGAMENTO EXCESSIVO

O catálogo não tenta mais pré-carregar automaticamente as páginas de detalhes,
consórcio e financiamento de todas as motos ao mesmo tempo.

6. TELA DE CARREGAMENTO

Foi adicionada uma tela skeleton. Em conexões lentas, o cliente vê a estrutura
do catálogo imediatamente em vez de uma tela vazia.

INSTALAÇÃO

1. Extraia este ZIP na pasta principal do projeto.
2. Confirme a substituição.
3. Não execute SQL.
4. Não adicione variáveis na Vercel.
5. Execute:

npm run typecheck
npm run lint
npm run build

6. Se os três comandos forem aprovados:

git add .
git commit -m "Melhora velocidade e carregamento do catalogo"
git push origin main

A Vercel criará o novo deployment automaticamente.

TESTE

1. Aguarde o deployment ficar Ready.
2. Abra uma janela anônima.
3. Acesse:

https://catalogo-honda.vercel.app/gd

4. Atualize a página algumas vezes.
5. Teste também usando a internet móvel do celular.
6. Entre em uma moto e volte ao catálogo.
7. Confirme imagens, botões, busca, consórcio e financiamento.

OBSERVAÇÃO

Esta entrega não altera:

- dados do Supabase;
- preços;
- vendedores;
- estrutura visual;
- painel administrativo;
- endereço do catálogo.
