ENTREGA 18.2 — PROTÓTIPO DE ASSINATURA E PAGAMENTOS

OBJETIVO

Demonstrar como Rafael poderá definir uma mensalidade diferente para cada
cliente e como o vendedor verá e pagará essa mensalidade no próprio painel.

ROTAS

/cliente-demo/login
/cliente-demo/dashboard
/cliente-demo/assinatura
/cliente-demo/admin-cobranca

PRINCIPAL TESTE

1. Abra:

http://localhost:3000/cliente-demo/admin-cobranca

2. Selecione GD Honda.
3. Altere:
   - valor da mensalidade;
   - dia de vencimento;
   - dias de tolerância;
   - status;
   - bloqueio automático.
4. Clique em Salvar mensalidade.
5. Abra:

http://localhost:3000/cliente-demo/assinatura

6. A mensalidade definida no simulador administrativo aparecerá no painel da
GD Honda.

A demonstração usa localStorage, por isso a alteração funciona somente no
mesmo navegador e computador.

PAGAMENTOS SIMULADOS

Na tela Minha assinatura é possível:

- abrir o pagamento Pix;
- visualizar QR Code simulado;
- copiar um código Pix fictício;
- simular pagamento aprovado;
- abrir cadastro de cartão;
- cadastrar um cartão fictício;
- alterar o status para Pago;
- visualizar histórico e regras de bloqueio.

IMPORTANTE

- nenhum pagamento real é processado;
- não use cartão ou dados reais;
- nenhum número completo de cartão é salvo;
- não cria usuário no Supabase;
- não executa SQL;
- não altera clientes reais;
- não altera o painel administrativo principal;
- não chama Asaas, Mercado Pago ou outro intermediador.

INSTALAÇÃO

Este pacote contém a versão completa do protótipo 18.2. Ele pode ser extraído
na raiz do projeto mesmo que a versão 18.1 já esteja instalada.

1. Extraia o ZIP na pasta principal do projeto.
2. Confirme a substituição da pasta app/cliente-demo.
3. Execute:

npm run typecheck
npm run lint
npm run build

4. Para testar no localhost:

npm run dev

5. Abra:

http://localhost:3000/cliente-demo/admin-cobranca

Depois:

http://localhost:3000/cliente-demo/assinatura

Nenhum commit ou deploy é necessário para avaliar pelo localhost.
