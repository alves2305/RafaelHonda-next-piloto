PAINEL ADMINISTRATIVO — FASE 3 / ENTREGA 13.1
CONSOLIDAÇÃO E CORREÇÕES DA AUDITORIA

O QUE FOI CORRIGIDO

- consórcio só aparece quando existem planos ativos;
- acesso direto ao consórcio sem planos é bloqueado;
- próxima moto no consórcio ignora modelos sem tabela;
- links de pré-visualização não usam mais /rafael fixo;
- o sistema procura um vendedor ativo e compatível para abrir a prévia;
- financiamento opcional não conta como etapa obrigatória;
- documentação de instalação foi atualizada;
- e-mail pessoal removido do SQL administrativo versionado;
- workflow de typecheck, lint e build incluído.

INSTALAÇÃO

1. Extraia o ZIP na pasta principal.
2. Confirme a substituição dos arquivos.
3. Não execute nenhum SQL no Supabase.
4. Execute:

npm run typecheck
npm run lint
npm run build
npm run dev

TESTES

1. Escolha uma moto sem planos ativos.
2. Confirme que o botão Planos de consórcio não aparece.
3. Tente abrir a URL de consórcio diretamente e confirme a página não encontrada.
4. Abra Planos ou Financiamentos no painel.
5. Confirme que Visualizar página pública abre um cliente que possui a moto.
6. Abra a configuração de uma nova moto.
7. Confirme que o progresso mostra 3 etapas obrigatórias.
8. Cadastre planos ou financiamento e selecione um vendedor.
9. Confirme que a moto pode ser publicada mesmo sem financiamento quando possui planos.

GITHUB ACTIONS

Após enviar os arquivos ao GitHub, a aba Actions executará automaticamente:

- npm ci;
- npm run typecheck;
- npm run lint;
- npm run build.

Nenhuma chave do Supabase é necessária para o build, pois o projeto possui
dados locais de demonstração quando as variáveis não estão configuradas.
